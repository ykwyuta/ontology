# 付録A 用語集

## オントロジー・知識表現

| 用語 | 意味 | 章 |
|------|------|----|
| オントロジー | ある分野のモノ・コトの種類、その間の関係、そこから言えるルールを、機械が読める形で書いたもの | 1 |
| 知識グラフ（ナレッジグラフ） | モノを点、関係を線として、大量の事実をグラフで持ったもの。オントロジーを型の定義として使うことが多い | 1, 8 |
| クラス | モノの種類。テーブル・Java のクラスに相当 | 2 |
| インスタンス | クラスに属する個々のモノ。行・オブジェクトに相当 | 2 |
| 属性（プロパティ） | インスタンスが持つ値。列・フィールドに相当 | 2 |
| サブクラス（is-a） | 「A ならば必ず B でもある」という種類の包含関係 | 2 |
| 関係（リレーション） | モノとモノのつながり。独立した概念として名前を付けて定義する | 3 |
| n 項関係 | 3 つ以上のものを結ぶ関係 | 3 |
| ロール | 関係の中で参加者が果たす役割（売主・買主など） | 3 |
| 推移的な関係 | A→B、B→C なら A→C も成り立つ関係（部品である、配下である） | 3, 4 |
| 推論 | 保存していない事実を、分類・関係の性質・ルールから導くこと | 4 |
| ルール | 「条件がそろえば結論が成り立つ」という規則 | 4 |
| 実体化（マテリアライズ） | 推論の結果を計算して保存しておくこと | 4 |
| 閉世界仮定 | 書いていないことは偽とみなす考え方 | 5 |
| 開世界仮定 | 書いていないことは不明とみなす考え方 | 5 |
| 失敗による否定 | 「導けなければ偽」とする否定。閉世界の否定 | 5, 14 |
| 層化否定 | ルールを層に分け、否定の中では下の層だけを使うことで、結果を一意に決める方法 | 5 |
| URI | 世界で一意になるように付ける、Web アドレスと同じ形式の ID | 6 |
| 標準語彙 | 広く共有されている概念の定義（schema.org など） | 6 |
| 上位オントロジー | 分野を問わない基本概念（モノ、出来事、時間など）の定義 | 6 |

## データベース・言語

| 用語 | 意味 | 章 |
|------|------|----|
| RDF | 主語・述語・目的語の三つ組でデータを表す W3C の標準 | 11 |
| トリプル | RDF の三つ組 | 11 |
| Turtle | RDF を人が読み書きしやすくした記法 | 11 |
| SPARQL | RDF の問い合わせ言語 | 11 |
| プロパティパス | SPARQL で関係を何段もたどる書き方（`p*` など） | 11 |
| OWL | RDF の上でクラスや関係の意味を論理的に定義する言語 | 11 |
| リーズナー | OWL の定義から分類や矛盾を推論するプログラム | 11 |
| SHACL | RDF のデータを閉世界で検証する W3C の標準 | 11 |
| RDF-star | 三つ組そのものについて三つ組を書く拡張（RDF 1.2 で標準化が進む） | 11 |
| プロパティグラフ | 属性を持つノードと、型・向き・属性を持つ線でデータを表す方式 | 12 |
| Cypher | Neo4j の問い合わせ言語 | 12 |
| GQL | プロパティグラフの問い合わせ言語の国際標準（ISO/IEC 39075、2024 年） | 12 |
| TypeDB | エンティティ・リレーション・属性の 3 種類の型でデータを表すデータベース | 13 |
| TypeQL | TypeDB の問い合わせ言語 | 13 |
| 関数（TypeDB） | TypeDB 3.x で推論のルールを書く仕組み。再帰と層化否定に対応 | 13 |
| Datalog | 事実とルールで書く、計算が必ず終わる論理プログラミング言語 | 14 |
| Prolog | 代表的な論理プログラミング言語 | 14 |
| ASP | 解集合プログラミング。層化できない否定や選択を扱える | 14 |
| 再帰 CTE | SQL の `WITH RECURSIVE`。階層を何段でもたどれる | 15 |
| EAV | エンティティ・属性・値の 3 列で何でも入れる汎用テーブル。RDB では避けたい設計 | 15 |
| SQL/PGQ | テーブルをプロパティグラフとして問い合わせる SQL の標準（SQL:2023） | 15 |
| R2RML | RDB のテーブルを RDF に対応づける W3C の標準 | 15 |

## 法律（第5部）

| 用語 | 意味 | 章 |
|------|------|----|
| 規範 | 「要件がそろえば効果が生じる」という法的なルール | 24 |
| 要件事実 | 法律の効果が生じるために必要な、具体的な事実 | 24 |
| 要件事実論 | 民事訴訟で、誰がどの事実を主張・立証すべきかを整理する理論 | 24 |
| 訴訟物 | 訴訟で審判の対象になる権利（売買代金支払請求権など） | 26 |
| 請求原因 | 請求を基礎づける事実。請求する側が立証する | 24 |
| 抗弁 | 請求原因から生じる効果を妨げる事実。請求される側が立証する | 24 |
| 再抗弁・再々抗弁 | 抗弁の効果を妨げる事実、さらにその効果を妨げる事実 | 24 |
| 証明責任 | ある事実が真偽不明のとき、その不利益を負う当事者の負担 | 5, 24 |
| 自白 | 相手の主張する不利な事実を認めること。証明を要しない | 5 |
| 規範的要件 | 「重大な過失」「正当な理由」など、評価を要する要件 | 24 |
| 準用 | ある規定を、別の事柄に必要な読み替えをして当てはめること | 23 |
| 経過措置 | 法改正のとき、改正前の事柄に新旧どちらの規定を適用するかを定めたもの（多くは附則） | 24 |
| 附則 | 法令の本体（本則）のあとに置かれる、施行日や経過措置などの規定 | 23 |
| PROLEG | 要件事実論を論理プログラムで表したシステム（国立情報学研究所の佐藤健氏ら） | 14 |
