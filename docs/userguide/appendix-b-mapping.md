# 付録B RDB / Java / オントロジー対応表

本書で扱った概念の対応を 1 枚にまとめます。「完全に同じ」ではなく「近いもの」の対応です。違いは各章を参照してください。

## 基本の部品

| オントロジー | RDB | Java | 違いのポイント | 章 |
|------------|-----|------|-------------|----|
| クラス | テーブル | クラス | 1 つのインスタンスが複数のクラスに属せる | 2 |
| インスタンス | 行 | オブジェクト | 条件を満たせば、あとから分類が決まる | 2, 4 |
| 属性 | 列 | フィールド | クラスから独立して定義・共有できる。複数の値を持てる | 2 |
| サブクラス | 継承の 3 通りの表し方 | `extends` | 実装の再利用ではなく「A ならば B」という主張 | 2, 15 |
| 制約（型・値の範囲・多重度） | 型・CHECK・NOT NULL | 型・enum・アノテーション | モデルの一部として共有できる | 2 |

## 関係

| オントロジー | RDB | Java | 違いのポイント | 章 |
|------------|-----|------|-------------|----|
| 二項関係 | 外部キー | 参照フィールド | 関係に名前と定義を付け、独立した概念として扱う | 3 |
| 関係の属性 | 中間テーブルの列 | 関係クラスのフィールド | 最初から関係に属性を持たせる | 3 |
| n 項関係 | 中間テーブル | 関係クラス | ロールつきでそのまま書ける方式もある（TypeDB） | 3, 13 |
| ロール | 外部キーの列名 | フィールド名 | ロールで問い合わせ、ロールを問わずにも問い合わせられる | 3 |
| 逆関係 | 同じ外部キーを逆向きに結合 | 双方向参照 | 名前を付けて宣言 | 3 |

## 推論と問い合わせ

| オントロジー | RDB | Java | 違いのポイント | 章 |
|------------|-----|------|-------------|----|
| 推移的な関係 | 再帰 CTE | 再帰メソッド | 関係の性質として宣言し、問い合わせる人は意識しない | 4, 15 |
| 条件で定義したクラス | ビュー | `isXxx()` | 問い合わせに組み込める | 4 |
| ルール | ビュー・ストアド・アプリのコード | サービスクラス | 業務の言葉で 1 か所にまとまり、根拠を追える | 4 |
| 実体化 | マテリアライズドビュー | キャッシュ | | 4 |
| 否定（閉世界） | `NOT EXISTS` | `!` | 層化否定で結果を一意にする | 5 |
| 不明（開世界） | NULL | `null`・`Optional` | 「書いていない」を「違う」と決めつけない | 5 |

## 共有と統合

| オントロジー | RDB | Java | 違いのポイント | 章 |
|------------|-----|------|-------------|----|
| URI・共通 ID | 主キー（テーブル内で一意） | 参照 | 世界で一意。システムごとの ID とは別に持つ | 6 |
| 概念の定義 | 設計書・コメント | Javadoc | モデルの一部として機械が読める | 6 |

| 概念どうしの対応（同じ・より狭い） | 変換テーブル | アダプタ | 対応の種類を書き分けられる | 6 |
