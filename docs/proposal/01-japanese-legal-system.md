# 1. 調査: 日本の法体系

TypeDB で表現する対象である日本の法体系について、モデル化に効く観点から整理します。

## 1.1 法源

日本は成文法主義（大陸法系）をとります。判断の根拠となる法源は次のとおりです。

| 区分 | 法源 | 根拠・備考 |
|------|------|-----------|
| 成文法 | 憲法 | 最高法規（憲法98条1項）。これに反する法律・命令等は効力を持たない |
| | 条約 | 国会の承認を経て国内法としての効力を持つ（憲法98条2項）。一般に法律より上位と解されている |
| | 法律 | 国会が制定する（憲法41条, 59条） |
| | 命令（政令・内閣府令・省令・外局規則等） | 内閣・各大臣が制定する。法律の委任または執行のために定める。一般に政令は府省令より上位 |
| | 議院規則・最高裁判所規則 | 憲法58条2項・77条に基づく |
| | 条例・地方公共団体の規則 | 「法律の範囲内」「法令に違反しない限り」で制定できる（憲法94条, 地方自治法14条1項） |
| 不文法 | 慣習法 | 法令の規定で認められたもの、または法令に規定のない事項について法律と同じ効力を持つ（法の適用に関する通則法3条）。商事については商慣習が民法に優先する（商法1条2項） |
| | 判例 | 制度上の一般的な拘束力はない。上級審の判断はその事件について下級審を拘束する（裁判所法4条）。実務上は最高裁判例が強い事実上の拘束力を持つ（判例変更には大法廷が必要: 裁判所法10条3号） |
| | 条理 | 明治8年太政官布告103号裁判事務心得3条に由来する補充的な法源 |

**モデル化への示唆**: 法源ごとに「種類」「制定主体」「優劣の順位」を属性として持たせます。判例は条文と同じ「規範の根拠」として扱いつつ、拘束力の強さ（大法廷判決・小法廷判決・下級審）を区別できるようにします。

## 1.2 法令の優劣と適用の原則

複数の規範が衝突したときの解決原則です。推論層での「どの規範を採るか」の判定に直結します。

| 原則 | 内容 | 例 |
|------|------|----|
| 上位法優先 | 形式的効力の高い法令が優先する | 憲法 > 法律 > 政令 > 省令、法令 > 条例 |
| 特別法優先 | 同じ事項について一般法と特別法があれば特別法が優先する | 民法と商法、民法と借地借家法・消費者契約法 |
| 後法優先 | 同じ順位の法令が衝突すれば新しいものが優先する | （通常は改正で明示的に解消される） |
| 法律不遡及・行為時法 | 原則として行為時の法を適用する。刑罰は事後法で科せない（憲法39条）。犯罪後に刑が変更された場合は軽いほうを適用する（刑法6条） | 改正法の附則にある経過措置 |

特別法優先は「後法でも一般法なら先にある特別法を覆さない」ため、上位・特別・後法の 3 原則は単純な全順序にはなりません。衝突解決は**規範どうしの優先関係（`overrides` 関係）として明示的にデータ化する**のが扱いやすいでしょう。

## 1.3 時間的な効力

- **公布・施行・失効**: 法令は公布後、附則で定める施行日から効力を持ちます。同じ法令でも条ごとに施行日が異なることがあります。
- **改正方式**: 日本では「一部改正法」が元の法令に溶け込む方式をとります。このため、ある時点で有効な条文の内容（版）を管理する必要があります。e-Gov 法令API v2 は時点を指定して条文を取得できます。
- **経過措置**: 附則で「施行日前に締結された契約については、なお従前の例による」などと定めます。典型例が 2020年4月1日施行の債権法改正（平成29年法律第44号）の附則です。
  - 例: 旧民法95条では錯誤は「無効」でしたが、新95条では「取り消すことができる」に変わりました。また、動機の錯誤は判例法理から明文化されました。どちらが適用されるかは、意思表示の時点と経過措置（附則6条1項）で決まります。

**モデル化への示唆**: 条文には「版（version）」を持たせ、`valid-from` と `valid-to` で有効期間を管理します。推論では「基準時点」を引数にとり、事実の発生時点と経過措置から適用する版を選びます。

## 1.4 条文の構造

法令は次のような入れ子構造を持ちます（法令標準XMLの要素名を併記）。

```
法令 Law
├─ 題名 LawTitle / 法令番号 LawNum
├─ 目次 TOC
├─ 本則 MainProvision
│   └─ 編 Part > 章 Chapter > 節 Section > 款 Subsection > 目 Division
│       └─ 条 Article（見出し ArticleCaption / 条名 ArticleTitle）
│           └─ 項 Paragraph（ParagraphNum）
│               ├─ 文 Sentence（Function="main" 本文 / "proviso" ただし書）
│               └─ 号 Item（ItemTitle）
│                   └─ 号の細分 Subitem1（イ・ロ・ハ）> Subitem2（(1)(2)）> ...
├─ 附則 SupplProvision（改正附則を含む）
└─ 別表 AppdxTable ほか
```

構造上の注意点:

- **枝番号**: 「第三条の二」のように後から挿入された条。条番号は整数ではなく `3_2` のような識別子として扱います。
- **削除**: 「第○条 削除」として番号だけが残ることがあります。
- **本文とただし書**: 1 つの項の中に「原則（本文）＋例外（ただし書）」が書かれます。これは推論上の例外関係に直結します。
- **前段・後段**: 1 つの項が 2 文からなる場合の呼び方です。
- **柱書と号**: 「次に掲げる場合には」（柱書）＋各号の列挙という形で、OR 条件や AND 条件を表します。

## 1.5 法令用語と論理構造

法令用語は、条文を論理式に変換するための重要な手がかりです。

| 用語 | 論理上の意味 | 備考 |
|------|------------|------|
| 及び / 並びに | AND | 1 階層なら「及び」、多階層なら小さい接続に「及び」、大きい接続に「並びに」 |
| 又は / 若しくは | OR | 1 階層なら「又は」、多階層なら大きい接続に「又は」、小さい接続に「若しくは」 |
| かつ | AND（強い結合） | |
| 場合 / とき | 条件（要件） | 条件が重なるときは大きいほうに「場合」、小さいほうに「とき」 |
| みなす | 擬制: 反証を許さずに効果を確定させる | 例: 民法886条1項 胎児は相続については既に生まれたものとみなす |
| 推定する | 反証可能な推定: 証明責任を相手方に移す | 例: 民法772条 嫡出推定、186条 占有の態様の推定 |
| この限りでない | 直前の規定を適用しない（例外） | ただし書の典型 |
| 前項の規定にかかわらず | 前項に優先する特則 | 優先関係 |
| 妨げない | 他の規定の適用を排除しない | 併存 |
| 準用する | 他の規定を必要な読み替えをして適用する | 参照グラフ。読み替えの対応表が必要 |
| 適用しない | 適用除外 | |
| 以上・以下 / 超える・未満 | 境界値を含む / 含まない | 数値比較 |
| 遅滞なく / 速やかに / 直ちに | 時間的即時性の程度 | 規範的な評価を伴う |

**モデル化への示唆**: 「みなす」と「推定する」は、推論上はっきり違う扱いになります。「みなす」は事実を確定させる規則として、「推定する」は証明責任を転換する規則（反対事実の証明があれば覆る規則）としてモデル化します。

## 1.6 利用できるデータ源

| データ | 提供元 | 形式・用途 |
|--------|--------|-----------|
| 現行法令・時点別条文 | e-Gov 法令検索 / 法令API Version2（2025年3月公開） | 法令標準XML（スキーマ v3）、JSON。時点を指定した取得、法令ID、改正履歴 |
| 法令標準XMLスキーマ | デジタル庁（e-Gov） | 条文構造の正規化された定義。取り込み処理の基礎 |
| 裁判例 | 裁判所「裁判例検索」 | 判決全文（構造化はされていない）。判示事項・裁判要旨の抽出が必要 |
| 民法の要件事実ルール | PROLEG（国立情報学研究所 佐藤健 研究室ほか） | Prolog 形式の規則。規範層の初期データや検証用の正解として参考にできる |
| 司法試験の民法短答問題 | COLIEE（国際競技会） | 条文と設問の含意判定データ。推論の正確さの評価に使える |

法令は著作権の目的とならず（著作権法13条1号）、判決も同様です（同条3号）。このため、条文そのものの取り込みに権利上の支障はありません（ただし、判例データベース業者の付加情報には別途の権利があり得ます）。
